# More Reforged Origins!

More custom origins specifically made for reforged (and hardened).

## The Undying

Every member of this company has access to the nine lives perk.

Additionally, the nine lives perk is updated with a "deaths door" mechanic
inspired by darkest dungeon.
If a brother would die (after triggering nine lives for the first time), they
instead make a resolve check.
If they succeed, then they live on, but with a -10 penalty to resolve for the
rest of the fight.
If they fail, they die forever and will not survive with a permanent injury.

Additionally, dying brothers will afflict all brothers who participated in the
combat with a new "I failed him" temporary injury, which forces them to enter
combat with the wavering or breaking morale state until it heals (5-10 days).
This is to prevent intentionally sacrificing brothers for this origin.
